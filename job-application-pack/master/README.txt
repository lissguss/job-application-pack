Положите в эту папку своё мастер-резюме в формате .docx.

ВАЖНО: название файла — только латиницей, без пробелов.
Правильно: master-resume.docx, ivanova-resume.docx
Неправильно: Резюме Иванова.docx
Если в названии есть русские буквы, при загрузке скилла появится ошибка «Zip entry has a Unicode Path extra field that does not match its filename».

Как составить мастер-резюме: откройте ../assets/resume-template.docx и заполните его своим опытом — целиком, со всеми местами работы, проектами и цифрами.

В папке должен лежать один .docx — ваш. Потом заархивируйте всю папку job-application-pack в .zip и загрузите в Claude: Настройки → Возможности → Навыки → Загрузить.

Обновлять резюме можно и без перезаливки скилла: просто приложите актуальный .docx к чату вместе с вакансией. Файл из чата важнее файла из этой папки, и для него название значения не имеет.
